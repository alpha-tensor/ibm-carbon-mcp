# Sources

This document outlines the data sources the IBM Carbon MCP server will pull from to power its tools.

## Primary IBM Carbon Sources

*   **Carbon Design System Website:** [https://carbondesignsystem.com/](https://carbondesignsystem.com/)
    *   *Usage:* Component guidance, usage rules, accessibility patterns, and foundation docs.
*   **Carbon Main GitHub Repository:** [https://github.com/carbon-design-system/carbon](https://github.com/carbon-design-system/carbon)
    *   *Docs:* `docs/` (Core guidelines and design system documentation).
    *   *React Package:* `packages/react/` (React components and code examples).
    *   *Main Packages Folder:* `packages/` (Other web components, icons, and pictograms).
*   **IBM Products GitHub Repository:** [https://github.com/carbon-design-system/ibm-products](https://github.com/carbon-design-system/ibm-products)
    *   *Usage:* Complex business and product components built on top of Carbon (`packages/ibm-products/src/components`).

## Template & Architecture Source

*   **AG-Grid MCP Template:** [https://github.com/ag-grid/ag-mcp](https://github.com/ag-grid/ag-mcp)
    *   *Usage:* Reference for standardizing MCP project structure, Typescript configuration, and tool handler paradigms.
